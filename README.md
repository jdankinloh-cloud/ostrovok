# Островок Детства — лендинг

Лендинг детского центра развития и досуга «Островок Детства» (Волгоград, ул. Химина 6). Дети от 9 месяцев до 7 лет.

Весь код — в одном HTML-файле: разметка + CSS + vanilla JS, без фреймворков и внешних зависимостей (кроме Google Fonts). Статические страницы — можно открывать напрямую в браузере или раздавать с любого статик-хостинга.

## Версии

| Файл | Дизайн |
|---|---|
| `index.html` | Версия 1 — минималистичный стиль: белые просторы, Inter Tight, тонкие линии, bento-сетка направлений |
| `index-v2.html` | Версия 2 — «мультяшный стикерпак»: кремовая бумага, чёрные обводки, жёсткие offset-тени, поляроиды и наклейки |
| `index3.html` | Экспериментальная версия |

## Что внутри

- Семантический HTML5, адаптив от 375px до десктопа
- Reveal-анимации на Intersection Observer, счётчики, аккордеон FAQ, плавающая навигация, бегущие строки
- Иконки — inline SVG-спрайт, без эмодзи и без библиотек
- Контактные ссылки: [tel:+79627599509](tel:+79627599509), [vk.com/ostrovok_detstva](https://vk.com/ostrovok_detstva)

## Публикация

Любой статик-хостинг (GitHub Pages, Netlify, Vercel): достаточно указать папку репозитория, точка входа — `index.html`.
